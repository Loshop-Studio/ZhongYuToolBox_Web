中育 ToolBox Windows WebView2 改造版

原项目：https://github.com/Loshop-Studio/ZhongYuToolBox_Web
基于提交：ca807d0
原作者：Loshop；Co-author：aoki

启动：解压便携包，在完整目录中双击“中育工具箱-aoki.exe”。
分享或移动时需保留 dist、DLL、bridge.js 等所有文件，不能只复制 exe。
适用：Windows 10/11 x64，.NET Framework 4.8，Microsoft Edge WebView2 Runtime。
此机器已安装所需运行时。本构建未进行代码签名。
WebView2 Runtime 官方说明：https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution

架构：C# WPF 原生窗口 + 系统 WebView2，发布包不包含 Electron、Node 或 node_modules。
浏览器渲染引擎仍然存在，由系统 WebView2 Runtime 提供。
WebView2 版与旧 Electron 使用不同的用户数据目录，不自动迁移旧 Electron 账号缓存。
用户数据：%LOCALAPPDATA%\ZhongYuToolbox-aoki-WebView2
同一 Windows 用户的各版便携包共享上述本地目录，重新解压或升级仍会记住登录状态。
“便携”表示无需安装，不代表账号缓存跟随解压目录。发布包不包含这个用户数据目录。
当前登录实现会在本地 WebView2 存储中保存 Token，以及供自动重登使用的账号和密码。
在用户中心退出登录可删除应用保存的登录凭据；不会因升级自动清除当前账号。
本地界面从 https://toolbox.local 加载，这个域名由宿主映射到随包 dist，不请求外部网页。
选课/专栏使用独立的远端 WebView2，退出页面时释放；远端页面没有原生文件读写桥。
HTTPS 保持证书校验。官方返回 HTTP 地址时沿用已经授权的 HTTP 连接。
原作者支持入口和捐赠对象保留。作者版本检查、统计和风控依赖移除。
Windows 发布包不包含 Everything 扫描程序，不执行风险扫描。

界面：
右上角选择“浅色 / 深色 / 跟随系统”，记住选择，跟随系统时实时响应系统变化。
灰紫暖白配色是 Quiet Violet / Cloud Dancer 的屏幕近似值，深色模式使用对应暗色变量。
得意黑 Smiley Sans v2.0.1 本地打包，授权见 dist/fonts/OFL.txt。
保留原作者 Loshop 和支持作者入口，新增 co-author aoki。
侧栏作为唯一功能导航，用户中心使用单一账号表单。
应用 Emil Design Engineering 的交互规则，参考 Wise Design 的层级、留白与圆角。

云笔记：
“PDF上传”：本机检查 CropBox 与已有旋转，只把可见竖版页逆时针旋转 90°。
内容随之旋转，横版/方形页不动，原文件不覆盖，矢量内容保留。
整页等比例适配 2880×1800 横版画布，居中留白，不裁切。
“图片上传”：多选 PNG、JPG、WebP，可上移/下移/移除，每张图片一页。
点击开始上传会先在本地 Worker 中生成 PDF，再进入笔记上传流程；预览不是必选步骤。
处理 EXIF 方向，透明区域铺白底，长边超过 4096 像素时等比例缩小。
自动模式下竖版图片逆时针旋转 90°；可逐张手动循环切换 0/逆时针90/180/270，手动方向不再被自动旋转覆盖。原图片不修改。
预览前 5 页，可以先保存生成的 PDF。上传完成可下载页面图片 ZIP。
上传资源使用实际 WebP 格式、MD5、SHA-256 引用及 OSS 返回地址。
本地保存由系统对话框选择路径，分块传输、临时文件写完后原子替换，取消不报成功。
固定模板通过受限桥读取，只允许 8 个模板路径。

验证：
npm run test:pdf：混合页方向、原文件不变、无效 PDF、模板重试、重复上传、
资源摘要/引用链、OSS URL、单调进度、固定模板路径限制通过。
真实 PDF.js 渲染：8 页混合方向、A4、方形、超宽/超长页的四角全部保留。
真实 WebView2 回归：主题、图片格式/顺序/方向、三页四角完整、损坏图片拒绝、
Worker 取消、监听收敛、桥权限限制、超过 2 MB 文件保存且逐字节验证、
已知服务跨域读取、远端视图加载/无原生桥/尺寸更新/退出释放通过。
UI 离线上传测试：未预览直接开始，自动生成 PDF，进度结束到 100%，没有真实远端写入。
生产包排除 tests 页面。
未用真实账号提交笔记；最终平板导入效果仍需真实设备验证。
没有量化旧版和新版的整体速度，不能据此宣称具体加速倍数。

构建：
npm ci
npm run test:pdf
npm run build:windows
需要 Windows 内置 .NET Framework C# 编译器，不需要 .NET SDK。
构建脚本缺少缓存时从官方 NuGet 下载固定版本 WebView2 SDK 1.0.4258.31。
产物：release/windows-webview2-时间戳/中育工具箱-aoki.exe
每次构建生成新目录，不覆盖正在使用的旧程序。

原生回归包：npm run test:windows
再运行回归包的 exe --qa；报告写到同目录 qa-result.json。
原生自检：exe --self-test，报告写到同目录 self-test.json。
源代码仍保留旧 Electron 构建用于对照，新发布程序采用 WebView2。

新增功能（1.1.1-aoki）：
云笔记列表提供重命名、移至官方回收站以及勾选后批量移动至文件夹/根目录。
移动前刷新服务端版本，逐条反馈，失败保留勾选，可重试或停止后续移动。
新测评默认显示已完成作业：打开作业、查看题目分析后识别本人错题；返回新测评，点击加入官方错题本。
识别使用 errorStudents 中的当前学生 ID，按 questionId 匹配；只展示审核结果，没有独立的本地错题本。
写入前重新确认分析和官方加入状态，超时后重试核对；官方错题本页面按科目导出 PDF。
选课预加载官方加密学生资料，避免读取空资料；页面支持重试、超时及网络失败提示。
官方错题写入、笔记移动及平板实际导入尚未用真实账号/设备验证，本版预发布。
后端依赖及离线分享变化详见 SERVER_DEPENDENCIES.md。

多文件上传：一次选择多个 PDF，每份单独保存，名称默认取各自文件名，可逐份编辑。
依次在本机转换并上传，展示每个文件的状态和总体进度；成功项不重复提交，失败项重试使用相同笔记 ID。
停止后续文件会完成当前文件，保留未上传项；预览与 ZIP 对应当前或最近成功上传的文件。
开始新一轮选择时名称刷新；图片成功上传后新选择会建立新笔记，清除上一轮图片。
应用图标为本 fork 的原创紫色笔记图标；源码中的 scripts/create-app-icon.ps1 可重新生成 SVG、PNG 和多尺寸 ICO。
