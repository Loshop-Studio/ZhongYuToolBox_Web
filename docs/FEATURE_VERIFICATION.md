核查时间：2026-10-03 / 04。这里记录证据和范围，不将模拟接口通过等同于真实账号联调。

## 本轮结果

- Windows 原生 WebView2 实际运行：**160 条断言通过**（144 种不同检查，部分查询按七个应用重复验证），包含本地图片/PDF 转换、业务错误处理、路由生命周期、原生分块保存、实际公开接口读取和随身答编码。原始结果见 [windows-qa.json](verification/windows-qa.json)。
- 9 组命令测试通过：`test:pdf`、`test:linspirer`、`test:apps`、`test:picture`、`test:stats`、`test:official-apks`、`test:android`、`test:ios`、`test:update`。Windows 上的 `test:ios` 原生 Swift 部分跳过，不能当作 iOS 编译通过。
- 新随身答浏览器测试：多页 SVG 640 × 1016，H.264 MP4 640 × 360 / 1.2 秒，视频和 AAC 音轨存在；预取消、中途取消、取消后重试通过。使用合成画板与 440Hz 音频。
- 更新页面实际查询 GitHub：发布前显示 1.1.12-aoki、更新说明和 Windows 下载链接，1.1.13-aoki 源码版正确提示高于当时正式版；发布后再次查询，正确显示 1.1.13-aoki 和“当前已是最新正式版”，并重新拍摄截图。
- iOS 前端生产构建通过。390 × 844 的浏览器布局测试中，画板缩放为正数，绘图区约 350 × 380；文字输入和撤销/重做入口可操作。这不是 iOS 真机触摸测试。
- 上游 [PR #10](https://github.com/Loshop-Studio/ZhongYuToolBox_Web/pull/10) 生产构建通过，沿用原作者 UI/UX 和统计代码；作者统计实现和登录调用相对当前上游没有改动。本 fork 正式包统计默认关闭。
- 实际 Fabric 回复编辑器新增 12 条断言通过：文字确实绘制到像素画布；两次撤销恢复空白；两次重做恢复编辑后的文字并仍可编辑；颜色撤销/重做正确；手机缩小不会反向放大；清空保留白色背景。
- 七个用户提供的官方 APK 已使用 `--official` 重新验证：版本与完整文件摘要识别、损坏文件拒绝全部通过。
- Android 1.1.13 最终构建、签名与 manifest 检查通过。iOS 最终 macOS 构建及 **4 项真实 WKWebView XCTest 通过**：iPhone 画板、专栏图片与返回、原生导航；iPad 横屏完整窗口、专栏与文章、原生返回及实际深色选中状态。运行见 [Build iOS IPA #52](https://github.com/nickfox395/ZhongYuToolBox_Web/actions/runs/37169435503)，原始摘要见 [ios-qa.json](verification/ios-qa.json)，设备 IPA 校验见 [ios-package.json](verification/ios-package.json)。

## 可复现验证

```sh
npm run test:pdf
npm run test:linspirer
npm run test:apps
npm run test:picture
npm run test:stats
npm run test:official-apks
npm run test:android
npm run test:ios
npm run test:update
npm run test:windows
```

`test:windows` 生成独立 QA 包；运行生成的 exe 加 `--qa` 后在该目录得到 `qa-result.json`、PDF 和画板导出文件。正式包不会包含 QA 页面。浏览器开发服务器下打开 `tests/board-export.html` 可手动重跑导出测试。macOS 云端工作流执行 iOS 原生编译、Swift 检查和模拟器 UI 测试。

未进行真实官方删除、笔记上传、回复发送、选课提交或设备配置操作。核心本地逻辑及已列出的接口契约通过，真实业务和设备差异仍不能标为全部正常。对已通过的实测结果信心高；对未覆盖的线上/真机项目状态未知。
